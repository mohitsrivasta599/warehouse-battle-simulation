
# Warehouse Battle Simulation

A grid-based multi-agent warehouse battle simulation using Python.

## Features
- Adjustable number of agents and enemies
- Random and Greedy controllers
- PPO reinforcement learning controller
- Animated 10x10 grid
- No obstacles

## Requirements
- Python 3
- Gymnasium
- Stable-Baselines3
- NumPy
- Matplotlib
- ipywidgets

## Run
Open Google Colab, install the dependencies, and run the simulation code.

Note: PPO training and simulation performance should be evaluated before treating the controller as production-ready.
